# java-lotto-precourse
기능 목록

- 로또 구입

구입 금액을 입력받는다

금액에 맞게 로또를 발행한다 (1장당 1,000원)

발행된 로또 수량과 번호를 오름차순으로 출력한다

- 로또 번호 생성

1~45 사이의 중복되지 않은 숫자 6개를 자동으로 뽑는다

랜덤 번호 생성을 위해 Randoms.pickUniqueNumbersInRange(1, 45, 6)을 사용한다

- 당첨 번호 입력

당첨 번호를 쉼표(,) 기준으로 입력받는다

보너스 번호를 입력받는다

번호 입력 후 당첨 내역을 계산한다

- 당첨 결과 계산

각 로또 번호와 당첨 번호를 비교하여 일치 개수를 계산한다

5개 + 보너스 번호 일치 시 2등으로 처리한다

당첨 결과(1~5등)와 해당 개수를 출력한다

수익률 = (총 상금 / 구입 금액) × 100 으로 계산하고, 소수점 둘째 자리에서 반올림한다


예외 상황
 
- 구입 금액

1,000원 단위가 아닐 경우 → [ERROR] 금액은 1000원 단위여야 합니다.

숫자가 아닌 입력일 경우 → [ERROR] 숫자를 입력해야 합니다.

- 로또 번호

로또 번호가 6개가 아닐 경우 → [ERROR] 로또 번호는 6개여야 합니다.

중복된 숫자가 포함된 경우 → [ERROR] 로또 번호는 중복될 수 없습니다.

범위(1~45)를 벗어나는 숫자 입력 시 → [ERROR] 로또 번호는 1부터 45 사이여야 합니다.

보너스 번호가 당첨 번호와 중복될 경우 → [ERROR] 보너스 번호는 당첨 번호와 중복될 수 없습니다.
